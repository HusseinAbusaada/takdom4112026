TAKADOM FOR PEACE - FLAT WEBSITE PACKAGE

All files are in ONE folder.
There are no assets/images subfolders.

This folder contains:
- index.html
- all other HTML pages
- styles.css
- script.js
- all image files used by the website

HOW TO PREVIEW:
1. Keep every file together in the same folder.
2. Open index.html in your browser.

For best results, run a local server from this folder:
    python -m http.server 8000

Then open:
    http://localhost:8000

IMPORTANT:
Do not move the images into another folder unless you also update their paths in the HTML/CSS files.
